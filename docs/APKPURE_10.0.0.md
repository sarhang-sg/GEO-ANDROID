# APKPure submission draft — NAV KURD 10.0.0

Package: `com.navkurd.app`. Version: `10.0.0` / `100000`. Minimum Android: API 24.

Use only the universal APK produced by the existing signed CI workflow. This source release has not been submitted to APKPure. Verify an in-place update over the previous signed app before publishing store copy.

## کوردی

- چاکسازیی جێگیری ئایکۆن و داتای نەخشە لە زووم و شاردنەوەدا.
- کەمکردنەوەی کاری دووبارەی نەخشە و سنووردارکردنی وردی ڕەندر لە ئامێرە لاوازەکان.
- چاکسازیی دۆخی ئەکاونت، چوونەدەرەوە و پاراستنی فۆڕم لە نوێبوونەوەی سێشن.
- نۆتیفیکەیشنی ئەکاونت لە ئەپی چالاکدا و چاکسازیی ڕێکخستنی کەش‌وهەوا.
- ڤێرژنی یەکگرتووی ١٠ و داتای ئۆفلاینی پشکنراو.

## العربية

- تحسين ثبات رموز الخريطة والبيانات أثناء التكبير وإخفاء الطبقات.
- تقليل العمل المتكرر وضبط كثافة الرسم للأجهزة محدودة الموارد.
- تحسين تسجيل الخروج وحماية النماذج أثناء تجديد الجلسة.
- إشعارات الحساب داخل التطبيق النشط وتحسين جدولة الطقس.
- إصدار موحد 10 وبيانات محلية مفحوصة.

## English

- More stable map markers and locality data through zoom and layer visibility changes.
- Less repeated work and bounded render density on constrained devices.
- More reliable account/session transitions and sign-out.
- Active-app account notifications and improved weather scheduling.
- Unified version 10 with verified local data.

Acceptance still required: installation over the previous APK, live GPS, notification permission/channel settings, widget refresh, battery restrictions, account operations and offline transitions on a physical device. Terminated-process account push requires a real backend/Firebase delivery configuration.
