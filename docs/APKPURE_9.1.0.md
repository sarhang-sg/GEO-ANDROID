## What’s New — کوردی

NAV KURD 9.1.0 نوێکردنەوەیەکی گەورەی ڕووکار، خێرایی و جێگیرییە:

- ڕووکاری نوێی لۆکس بە شینی قووڵ، سپی و سیانی براندی؛ شیشەیی و ئەنیمەیشنی سادە و خێرا.
- گەڕان لە شوێنی گونجاوی سەرەوە دانرا و گلیچی گەڕان/GPS کە ماپەکەی دەگەڕاندەوە چارەسەر کرا.
- دوگمەکانی ماپ و Settings پاک، یەکسان، ئایکۆن‌محەوەر و وەڵامدەرەوەی touch بوون.
- لۆدینگی نوێ و مۆدێرن و بەشی نوێی داگرتنی APK زیاد کرا.
- هاوبەشکردنی شوێن ئێستا شیتی ناتیڤی Android دەکاتەوە.
- زیادکردنی وێنە بۆ شوێن چارەسەر کرا؛ هەڵبژاردن و کۆمپریسکردن چیتر پەڕەکە بەتاڵ ناکات.
- ناوی شوێن لە پۆپ‌ئەپی ماپدا لەگەڵ ئایکۆنی جۆری شوێن پیشان دەدرێت.
- ویجێتی کەش‌وهەوا لە بنەڕەتەوە ڕێکخرایەوە: دووبارەبوونەوەی خۆر/مانگ/هەور لابرا، فۆنتی ئەپ بەکار هێنرا و نوسین/ئایکۆنەکان بۆ کوردی، عەرەبی و ئینگلیزی ڕێکخران.
- کلیک لە ویجێت چیتر ئەپەکە ڕیفرێش ناکات و دۆخی ئێستای ماپ دەپارێزێت.
- هەڵەکانی `Invalid URL`، `ERR_FAILED` ـی داواکاریی هەڵوەشاوە و هەندێ هەڵەی پلەی ناتیڤ پاک کرانەوە.
- فێرکاری، پرۆگرێس بار، مێنیو و دەربارە نوێ کرانەوە؛ ڕەنگی بەشی پارەدان و پشتگیری وەک خۆی پارێزرا.
- کش، خەزن، سێ زمان، ئۆفلاین، ڕێنیشاندان، نۆتفیکەیشن و پلەی پاراستن/پشتگیریی Android باشتر کران.

## What’s New — English

- New luxe deep-blue, white and cyan interface with restrained, responsive motion.
- Search now sits in the correct safe-top position; search and shared-location moves no longer fight GPS camera follow.
- Clean, consistent touch controls and compact Android settings actions.
- New Loading composition and redesigned verified direct-APK section.
- Fixed native Android sharing and place-photo selection/compression.
- Place category icons now appear beside popup titles.
- Rebuilt multilingual weather widget with one weather symbol, app-matching fonts, clean metrics and no app reload when tapped.
- Hardened malformed URL handling, cancelled WebView requests, offline behavior, notifications and release checks.

## Publisher checklist

1. Use only the CI-produced signed universal APK.
2. Verify package/version and the established certificate fingerprint.
3. Record the APK SHA-256 and test an in-place update over the previously installed signed release.
4. Test Kurdish, Arabic and English; widget refresh/tap; GPS/search; sharing; image selection; notifications; offline pack.
5. Paste the appropriate What’s New language block into APKPure.
