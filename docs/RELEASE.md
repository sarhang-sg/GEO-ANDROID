# NAV KURD Android 11.0.0

Version name 11.0.0 and version code 110000 identify the application. The map presentation, Android launcher widgets and native weather activity support Kurdish, Arabic and English.

This release keeps the split Loading animation on map launch. Widget city and temperature taps open weather directly. The widget renderer handles all launcher sizes and preserves the latest bitmap across a resize. The web and Android map views share the same search, contrast tokens, 3D location marker and city directory.

The native catalog remains independently versioned. Release automation verifies SQLite and PMTiles integrity, Flutter analysis and tests, the launcher smoke test and the Android signing certificate. Public binaries carry the established application ID and signing identity.
